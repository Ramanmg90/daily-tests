# راه‌اندازی قدم به قدم

1. توی تلگرام برو سراغ باتت و دکمه‌ی Start رو بزن (یا یه پیام بده).
2. توی github.com ثبت‌نام کن. بعد + بالا سمت راست، New repository، یه اسم بذار، گزینه‌ی **Private** رو انتخاب کن و Create.
3. این زیپ رو extract کن. توی صفحه‌ی ریپو روی "uploading an existing file" کلیک کن و **همه‌ی محتوای پوشه** (از جمله پوشه‌ی .github) رو بکش و بنداز. بعد Commit changes.
   - اگه پوشه‌ی .github آپلود نشد: Add file > Create new file، اسم رو بنویس `.github/workflows/daily.yml` و محتوای فایل daily.yml رو paste کن.
4. (اختیاری) Settings > Secrets and variables > Actions > Variables: سه تا متغیر بساز با اسم‌های SUBJECT (مثلاً ریاضی)، GRADE (مثلاً پایه نهم)، LANGUAGE (مثلاً فارسی). اگه نسازی، پیش‌فرض ریاضی/نهم/فارسی استفاده می‌شه.
5. تب Actions > اگه دکمه‌ی فعال‌سازی دید، بزن > daily-tests > Run workflow. بعد از ۲ تا ۳ دقیقه باید پیام و PDF توی تلگرام برسه.

ساعت ارسال: توی daily.yml خط cron (به وقت UTC). الان ۱۲:۰۰ UTC = ۱۵:۳۰ ایران.
بعداً توکن‌ها رو عوض کن: فایل local_secrets.py رو توی گیت‌هاب ویرایش کن.

# ساخت سوال با هوش مصنوعی (RoboRam)

## چت‌بات
```
pip install -r requirements.txt
export AVALAI_API_KEY="..."        # ویندوز: set AVALAI_API_KEY=...
python roboram.py
```
توی چت یکی از این‌ها رو بنویس:
- `/test` ← قدم‌به‌قدم می‌پرسه
- `/test ریاضی | نهم | مجموعه‌ها | تیزهوشان | 10`
- یا ساده: «۱۰ تا تست ریاضی نهم از فصل مجموعه‌ها در سطح تیزهوشان بساز»

خروجی توی پوشه‌ی `output/` (PDF + متن) ذخیره می‌شه و می‌تونی بفرستی‌ش تلگرام. سوال‌ها توی حافظه‌ی گفتگو هم می‌مونن؛ می‌تونی بپرسی «راه‌حل سوال ۴ رو ساده‌تر توضیح بده».

## سطح‌ها
| سطح | یعنی |
|---|---|
| کتاب | مثال و تمرین کتاب درسی |
| نمونه | در حد آزمون‌های مدارس نمونه دولتی؛ ترکیب مفاهیم و چند مرحله استدلال |
| تیزهوشان | در حد آزمون ورودی تیزهوشان؛ مسئله‌های خلاقانه و ایده‌محور |

## کنترل کیفیت (چرا سوال‌ها مطمئن‌ترند)
هر سوال بعد از ساخت به یک «حل‌کننده‌ی مستقل» داده می‌شه که کلید رو نمی‌بینه. سوال فقط وقتی می‌مونه که
جواب حل‌کننده با کلید یکی باشه، دقیقاً یک گزینه‌ی درست داشته باشه، مال همون پایه باشه و سختی‌ش توی بازه‌ی سطح انتخابی بخوره.
سوال تکراری (نسبت به `questions.txt` و `generated_questions.txt`) هم حذف می‌شه و جای گزینه‌ی درست تصادفی جابه‌جا می‌شه.
باز هم قبل از پخش بین دانش‌آموزان یه نگاه سریع به پاسخنامه بنداز.

## بات روزانه‌ی تلگرام
- توی GitHub: Settings > Secrets and variables > Actions > **Secrets** یه secret به اسم `AVALAI_API_KEY` بساز.
- متغیرهای (Variables) جدید: `LEVEL` (کتاب/نمونه/تیزهوشان) و `MODE`.
- `MODE` خالی: اول سوال‌های `questions.txt` رو می‌فرسته و وقتی تموم شد به‌جای تکرار، سوال تازه با AI می‌سازه.
- `MODE=ai`: از همون روز اول هر روز ده سوال تازه می‌سازه.
- متغیر `TOPICS` حالا کار می‌کنه: مثلاً «عبارت‌های جبری و معادله‌ی خط».
